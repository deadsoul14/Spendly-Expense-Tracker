# Spendly — Expense Tracker

A responsive React expense tracker with:
- Dashboard with spending summaries
- Add, edit and delete transactions
- Search, category and month filters
- Custom categories with colours
- Spending analytics and monthly trend charts
- CSV export
- Dark and light themes
- Browser localStorage persistence

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Data storage

Transactions, categories and theme preference are saved in your browser's localStorage. Data is local to the browser/device and is not synced to a server.
